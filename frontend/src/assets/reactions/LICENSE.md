# Reaction artwork

The four SVGs in this directory are the *Flat* style of Microsoft's
[Fluent Emoji](https://github.com/microsoft/fluentui-emoji) — Red heart, Face with
tears of joy, Face with open mouth, and Fire — copied unmodified.

They are bundled rather than rendered as Unicode emoji because emoji fonts place their
glyphs on different baselines per platform, so a count beside one lands somewhere
different in every browser. An image in a fixed box lands in the same place everywhere
(#520).
